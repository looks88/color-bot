# 达芬奇校色工具 DaVinci Color Studio

专业视频校色与风格化处理桌面工具，支持自动场景剪切、智能光影修复、电影级风格滤镜和实时分屏对比。

## 功能特性

### 🎬 自动场景剪切
- 基于 HSV 直方图差异的智能场景检测
- 可调节敏感度阈值和最短场景长度
- 自动识别视频中的镜头切换点
- 支持按场景单独预览和导出

### ✨ 智能光影修复
- **自动曝光修复**：直方图拉伸 + 对数空间亮度均衡，修复欠曝/过曝
- **自动白平衡**：灰度世界假设 + 完美反射修正
- **暗部提亮**：基于亮度蒙版的智能阴影恢复
- **高光压制**：高光细节恢复，避免过曝死白
- **降噪处理**：非局部均值彩色降噪

### 🎨 专业校色调整
- 亮度 / 对比度 / 饱和度
- 色温（冷暖）/ 色调（绿-品红）
- Gamma 曲线调整

### 🎭 16种电影级风格滤镜
| 分类 | 滤镜 |
|------|------|
| 电影 | 青橙色调、暖调电影、冷调电影 |
| 复古 | 复古胶片、棕褐色、70年代 |
| 清新 | 清新通透、日系清新 |
| 黑白 | 高对比黑白、银盐黑白、柔和黑白 |
| 创意 | 梦幻柔光、黑色电影、鲜艳浓郁、褪色哑光 |

### 👁 实时预览
- 左右分屏对比（原图 vs 校色后）
- 可拖动分割线
- 支持逐帧浏览 / 播放预览
- 拖拽视频文件直接打开

### 💾 多格式导出
- MP4 (H.264) / AVI / MOV / WebM
- 支持全片导出或单场景导出
- 支持导出当前帧为图片

## 快速开始

### 方式一：直接运行源码（开发/调试）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行程序
python main.py
```

### 方式二：打包为 Windows EXE

```bash
# 在 Windows 系统上双击运行
build_windows.bat

# 或手动执行
pip install -r requirements.txt pyinstaller
pyinstaller --clean --noconfirm build.spec
```

打包完成后，EXE 文件位于 `dist/达芬奇校色工具.exe`

## 使用流程

1. **导入视频**：点击「导入视频」或直接拖拽视频文件到窗口
2. **场景检测**（可选）：切换到「场景剪切」标签，调整参数后点击「自动检测场景剪切」
3. **校色调整**：在「校色调整」标签中开启光影修复，微调各项参数
4. **风格滤镜**（可选）：在「风格滤镜」标签选择滤镜并调节强度
5. **预览对比**：使用分屏对比查看效果，拖动滑块浏览视频
6. **导出视频**：切换到「导出」标签，选择格式后点击「导出校色后视频」

## 系统要求

- **操作系统**：Windows 10/11（推荐）/ macOS / Linux
- **Python**：3.9 ~ 3.12
- **内存**：建议 4GB 以上
- **磁盘**：视频处理需预留足够临时空间

## 项目结构

```
davinci_color_tool/
├── main.py                  # 程序入口
├── requirements.txt         # Python 依赖
├── build.spec               # PyInstaller 打包配置
├── build_windows.bat        # Windows 一键打包脚本
├── README.md                # 说明文档
├── core/                    # 核心算法模块
│   ├── video_loader.py      # 视频加载
│   ├── scene_detector.py    # 场景检测
│   ├── color_correction.py  # 色彩校正/光影修复
│   ├── filters.py           # 风格化滤镜
│   └── video_exporter.py    # 视频导出
└── gui/                     # 界面模块
    ├── main_window.py       # 主窗口
    ├── preview_widget.py    # 预览组件
    └── control_panel.py     # 控制面板
```

## 技术栈

- **GUI 框架**：PySide6 (Qt for Python)
- **视频处理**：OpenCV
- **数值计算**：NumPy / SciPy
- **打包工具**：PyInstaller
