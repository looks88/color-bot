              达芬奇校色工具 - 使用说明
═══════════════════════════════════════════════════════════════

【快速生成 EXE】
  双击运行「一键打包EXE.bat」
  → 脚本自动下载便携版Python → 安装依赖 → 打包EXE
  → 完成后EXE位于 dist\达芬奇校色工具.exe
  （无需预先安装任何软件，全程自动）

【如果已有Python环境】
  方式A：双击「启动程序(开发模式).bat」直接运行
  方式B：双击「build_windows.bat」快速打包EXE
  方式C：双击「Nuitka高性能打包.bat」编译为原生机器码（更快）

【功能说明】
  • 自动场景剪切：智能识别视频中的镜头切换
  • 智能光影修复：自动曝光/白平衡/暗部提亮/高光压制
  • 16种电影滤镜：青橙/复古/日系/黑白/梦幻等
  • 实时分屏对比：左右对比原图与校色效果
  • 多格式导出：MP4/AVI/MOV/WebM

【操作流程】
  1. 拖拽视频到窗口，或点击「导入视频」
  2. （可选）场景剪切标签 → 自动检测场景
  3. 校色调整标签 → 开启光影修复，微调参数
  4. （可选）风格滤镜标签 → 选择滤镜并调强度
  5. 导出标签 → 选择格式 → 导出视频

【系统要求】
  Windows 10/11，64位系统，4GB以上内存
